# 🎓 EduVault Prime

An AI-powered education platform designed to make learning smarter, faster, and more interactive.

---

## 🚀 Live Demo

👉 https://eduvault-prime.lovable.app

---

## ✨ Features

- 🤖 AI Tutor
- 📚 Smart Notes
- 📝 Mock Tests
- 📊 Student Dashboard
- 📈 Progress Tracking
- 🎯 Personalized Learning
- 🔐 Secure Authentication
- 📱 Responsive Design

---

## 🛠️ Built With

- React
- TypeScript
- Vite
- Supabase
- AI Integration
